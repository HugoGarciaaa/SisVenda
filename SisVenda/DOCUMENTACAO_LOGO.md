# Logo SisVenda - Documentação

## Versão Criada

Uma logo moderna e profissional foi criada para o aplicativo SisVenda com as seguintes características:

### Design
- **Cores Principais**: Azul (#2563EB) e variações de azul mais claras
- **Cor de Destaque**: Verde (#22C55E) para a seta de crescimento
- **Estilo**: Minimalista e moderno com gráficos de barras e seta de crescimento

### Componentes da Logo
1. **Gráfico de Barras**: Representa análise de dados e crescimento
2. **Seta Verde Ascendente**: Representa crescimento e positividade
3. **Círculo de Fundo**: Proporciona contraste e suporte visual

## Arquivos Criados

### 1. `sisvenda_logo.svg` (Logo Quadrada)
- **Dimensão**: 200x200px
- **Uso**: Ícone do aplicativo, menu lateral, cabeçalho
- **Localização**: `Resources/Images/sisvenda_logo.svg`

### 2. `sisvenda_logo_horizontal.svg` (Logo Horizontal)
- **Dimensão**: 400x150px
- **Uso**: Página inicial, splash screen, banners
- **Localização**: `Resources/Images/sisvenda_logo_horizontal.svg`

## Uso na Aplicação

### Página Inicial
A logo SVG quadrada foi integrada na página inicial (`MainPage.xaml`) ao lado do nome "SisVenda", criando uma apresentação profissional e moderna.

### Estrutura Visual da Página Inicial
- Logo + Nome em destaque
- Bem-vindo com descrição
- Lista de funcionalidades principais com ícones
- Botão "Começar a Usar" que navega para produtos
- Footer com informações de versão

## Personalização

Para modificar as cores da logo, edite os arquivos SVG:
- `#2563EB`: Azul principal
- `#3B82F6`: Azul médio
- `#60A5FA`: Azul claro
- `#F0F7FF`: Fundo muito claro
- `#22C55E`: Verde de crescimento
