# Guia Rápido: Painel de Carrinho de Compras

## ?? Como Usar a Tela de Vendas

### Passo 1: Acessar a Tela de Vendas
- Navegue até "Detalhes da Venda" na aplicação

### Passo 2: Preencher Informações Básicas
1. **Defina a Data**: Clique no DatePicker para definir a data da venda
2. **Selecione o Cliente**: Clique no Picker de clientes e escolha um cliente

### Passo 3: Adicionar Produtos
1. **Clique no Picker de Produtos**: Uma lista de todos os produtos disponíveis será exibida
2. **Selecione um Produto**: Escolha o produto desejado
3. **Visualize os Detalhes**:
   - A imagem do produto será exibida no painel esquerdo
   - Veja o código, categoria, descrição e preço
4. **Informe a Quantidade**: Digite a quantidade no campo "Quantidade"
5. **Clique em "Adicionar"**: O produto será adicionado ao carrinho

### Passo 4: Gerenciar Carrinho
- **Ver Detalhes**: O painel direito mostra todos os itens com:
  - Imagem miniatura
  - Nome e código
  - Categoria
  - Preço unitário
  - Quantidade
  - Subtotal de cada item

- **Remover Item**: Clique no botão "?" vermelho à direita do item

### Passo 5: Verificar Resumo
- **Quantidade de Itens**: Visto no rodapé do carrinho
- **Valor Total**: Exibido em verde no resumo

### Passo 6: Confirmar Venda
1. Verifique se todos os itens estão corretos
2. Clique em "Confirmar Venda" para finalizar
3. A venda será salva no banco de dados

### Passo 7: Cancelar (se necessário)
- Clique em "Cancelar" para descartartodos os itens e sair

## ? Validações Automáticas

- ? Quantidade deve ser um número maior que zero
- ? Deve selecionar um produto
- ? Deve selecionar um cliente
- ? Carrinho deve ter pelo menos um item

## ?? Dicas

1. **Revisão Rápida**: Sempre revise o carrinho antes de confirmar
2. **Edição**: Se errou, remova o item e adicione novamente com a quantidade correta
3. **Múltiplos Produtos**: Você pode adicionar quantos produtos quiser
4. **Produtos Duplicados**: Se adicionar o mesmo produto novamente, aparecerá como um novo item (recomenda-se remover o anterior e readicionar com a quantidade total)

## ?? Elementos Visuais

- **Azul (#007AFF)**: Preços unitários e elementos de ação
- **Verde (#34C759)**: Totais e resumo do carrinho
- **Vermelho (#FF3B30)**: Botões de cancelamento e remoção
- **Cinza**: Informações secundárias e descritivas

## ? Solução de Problemas

| Problema | Solução |
|----------|---------|
| Não consigo adicionar um produto | Verifique se selecionou um produto e informou uma quantidade válida |
| O produto não aparece no carrinho | Clique no botão "Adicionar" após preencher a quantidade |
| Quer remover um item | Clique no botão "?" vermelho à direita do item |
| Quer cancelar tudo | Clique em "Cancelar" na parte inferior |
